# Kubo — Architecture Decision Records

ADRs record material choices, alternatives, rationale, and consequences. Accepted decisions are the first implementation baseline; changes require a superseding ADR or an explicit update reviewed with the affected architecture documents.

## Status definitions

- **Proposed:** Documented direction awaiting an owner decision.
- **Accepted:** Selected baseline for implementation; detailed service-level specifications may still be required.
- **Rejected:** Considered but not selected.
- **Superseded:** Replaced by a later decision.

Acceptance does not imply production readiness or that deferred details can be omitted from implementation.
